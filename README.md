# Data Analytics Portfolio

A simple, responsive, two-page portfolio website for GitHub Pages.

## Files
- `index.html` - homepage, skills, project placeholders, and contact links
- `about.html` - About Me page with headshot and professional introduction
- `styles.css` - site styling
- `assets/headshot.png` - generated professional headshot

## Before publishing
1. Open `index.html` and `about.html`.
2. Replace `YOUR_EMAIL@example.com` with your professional email address.
3. Replace `YOUR-LINKEDIN-URL` with the part of your LinkedIn profile URL after `linkedin.com/in/`.
4. Review the introduction and skills so they accurately reflect your experience.
5. Update the technical toolkit as you gain and demonstrate skills.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository (for example, `my-portfolio`).
2. Upload all files and folders from this project. Keep `index.html` at the repository's top level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for the Pages deployment. GitHub will show the published website URL in the Pages section.

Do not publish until your real email and LinkedIn URL have replaced the placeholders.
